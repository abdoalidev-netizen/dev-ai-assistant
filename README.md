## 🌟 أبرز الميزات والشاشات

### 1. شاشة البداية والترحيب (Splash & Onboarding)
- شاشة Splash متحركة مع توهج الشعار وظهور اسم "Dev" و"by Abdo Ahmed Ali" بتدرج لوني فخم.
- 3 شرائح ترحيب تفاعلية تشرح إمكانيات التطبيق ومميزاته.
- تخصيص الاسم واللغة (عربي RTL أو إنجليزي LTR) والمظهر (داكن Luxe وفاتح Clean).
- شرح راقٍ لصلاحيات الميكروفون والكاميرا، ويعمل التطبيق بسلاسة تامة حتى لو رُفضت الصلاحيات.

### 2. شاشة المحادثة الذكية (Chat Screen)
- **بث تدفقي حي (Streaming)** حرفاً بحرف مع مؤشر كتابة وزر إيقاف التوليد في أي لحظة.
- فقاعات رسائل مميزة: رسائل المستخدم بتدرج بنفسجي/وردي فخم، وردود Dev بخلفية زجاجية أنيقة.
- **عرض Markdown كامل**: جداول منظمة، قوائم نقطية ورقمية، وتنسيق الأكواد البرمجية مع تلوين الصياغة وزر نسخ وزر شرح الكود.
- أزرار التحكم لكل رد: نسخ، مشاركة، استماع صوتي (TTS)، إعادة التوليد، تقييم 👍👎، وإضافة للمفضلة.
- **بحث حي في الويب (Search Grounding)**: استخراج المصادر المرجعية وعرضها كبطاقات روابط تحت الرد.
- إدخال ذكي متعدد الوسائط: كتابة، إملاء صوتي، صور من الكاميرا أو المعرض، وروابط.

### 3. استوديو الصور (AI Image Studio)
- كتابة وصف الصورة بالعربية، مع زر **تحسين البرومبت بـ Gemini** لتحويله إلى برومبت إنجليزي احترافي يحدد الإضاءة والزوايا والعدسات.
- خيارات أنماط متعددة: واقعي، سينمائي، ثلاثي الأبعاد، أنمي، رسم زيتي، شعار، ملصق، وتصوير منتجات.
- نسب أبعاد متنوعة: `1:1`, `9:16`, `16:9`, `4:5`.
- توليد الصور عبر نموذج `gemini-2.5-flash-image` وحفظها في معرض محلي مع إمكانية المعاينة بملء الشاشة والمشاركة.

### 4. الأدوات الذكية (Smart Tools)
1. **المترجم الفوري**: ترجمة سياقية مع بدائل ونطق.
2. **محلل الصور وOCR**: استخراج وتلخيص وفهرسة نصوص الوثائق والصور.
3. **ملخّص الملفات والروابط**: استخراج ملخص موجز وأهم النقاط الرئيسية.
4. **مساعد الكتابة**: إعادة صياغة، تدقيق لغوي، وتغيير النبرة.
5. **مساعد البرمجة**: كتابة وإصلاح وشرح الأكواد البرمجية.
6. **صانع البرومبتات**: تحويل الأفكار إلى أوامر احترافية خارقة.
7. **المعلّم الشخصي**: شرح المفاهيم بأسلوب فاينمان مع اختبارات تفاعلية.
8. **الحاسبة والمسائل**: حل المعادلات الرياضية خطوة بخطوة.

### 5. الأوضاع والشخصيات (Personas)
تبديل فوري بين أوضاع Dev المجهزة:
- المبرمج المحترف (Code Master)
- المترجم اللغوي (Polyglot)
- الكاتب الإبداعي (Author)
- المعلّم الأكاديمي (Tutor)
- محلل البيانات (Data Analyst)
- خبير التصميم (UI/UX Designer)
- المدرب الشخصي (Personal Coach)

### 6. تنفيذ أوامر الجهاز (Device Actions)
- ضبط منبهات، تشغيل مؤقتات، إضافة مواعيد للتقويم، وتجهيز رسائل بريد.
- **أمان وشفافية مطلقة**: يظهر للمستخدم دائماً مربع حوار ملخص وزر "تأكيد" قبل تنفيذ أي إجراء.

### 7. سجل المحادثات والخصوصية (History & Privacy)
- حفظ محلي كامل عبر **Room Database**.
- تثبيت المحادثات المهمة، مفضلة، بحث، وإعادة تسمية.
- تصدير المحادثات بأربع صيغ: **Markdown**, **PDF Text**, **TXT**, **CSV**.

### 8. الذاكرة طويلة المدى (Long-term Memory)
- إمكانية حفظ تفضيلات المستخدم الخاصة واستعراضها وتعديلها وحذفها في أي وقت.

## 🔑 ضبط مفتاح الـ API

يتم حقن مفتاح Gemini API تلقائياً في بيئة AI Studio عبر **Secrets Panel** بدون كتابة المفتاح يدوياً داخل الكود:
1. افتح لوحة **Secrets** في AI Studio.
2. أضف المفتاح باسم `GEMINI_API_KEY`.
3. سيتولى Secrets Gradle Plugin حقن المفتاح في `BuildConfig.GEMINI_API_KEY`.
4. يمكنك أيضاً إدخال مفتاح مخصص مباشرة من شاشة **الإعدادات** داخل التطبيق.
